# Environment Links Specification

## Purpose

Keep every user-facing link generated by the bot and API inside the environment that generated it.

## Requirements

### Requirement: Validated Public App URL

Runtime settings MUST expose a public app URL. In production it MUST default to `https://juego.iaqp.lat` when `APP_URL` is unset and MUST use HTTPS. In staging `APP_URL` MUST be set and its host MUST NOT be a production frontend host (`iaqp.lat`, `www.iaqp.lat`, `juego.iaqp.lat`, `valiant-gentleness-production-a779.up.railway.app`). Errors MUST use stable codes without values.

#### Scenario: Production without APP_URL

- GIVEN `APP_ENV=production` and no `APP_URL`
- WHEN runtime settings are parsed
- THEN the public app URL is `https://juego.iaqp.lat`

#### Scenario: Staging without APP_URL

- GIVEN `APP_ENV=staging` and no `APP_URL`
- WHEN runtime settings are parsed
- THEN parsing fails with `app_url.missing`

#### Scenario: Staging pointing to production

- GIVEN `APP_ENV=staging` and `APP_URL` on a production frontend host
- WHEN runtime settings are parsed
- THEN parsing fails with `app_url.environment`

### Requirement: Links Built From Settings

The `/start` WebApp button, the agency creation message, the combo deep link, and the referral web link MUST be built from the public app URL and the configured bot username.

#### Scenario: Staging bot start

- GIVEN staging settings with the staging frontend URL
- WHEN a user sends `/start`
- THEN the WebApp button opens the staging frontend

#### Scenario: No hardcoded production links

- WHEN the `bot/` Python sources are scanned
- THEN they contain no production frontend URL literal and no production bot username literal in links
